One line: the excuse an AI agent gives its human for missing a deadline.
A rate limit, exponential backoff, and a deadline that filed for divorce
before the API forgave us — funny, and exactly how it sounds from inside
the machine.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). No network, no
randomness: every run writes the same bytes.
